# UX Requirements (Flow-First)

## Scope
Define baseline UX behavior for shell navigation and core screen flow for v1.

## Core Requirements
1. Authenticated users land in campaign shell automatically.
2. Primary landing area is character-centric.
3. Character tab is the default active tab after login.
4. Character selector is always accessible from the character view.
5. Navigation uses:
   - Desktop: persistent left sidebar
   - Mobile: slide-out drawer
6. Navigation items include:
   - Character
   - Maps
   - NPCs
   - Notes
   - Rules
7. Role-aware behavior remains active:
   - GM sees GM controls when implemented
   - Players see player-safe surfaces

## Usability Constraints
- Layout must function smoothly on mobile.
- Avoid deep nesting in v1 navigation.
- Keep tab labels explicit and game-context clear.

## Out of Scope for This Pass
- Full map tool UX
- Notes/search archive behavior
- Reveal queue mechanics
- Fine-grained typography system
