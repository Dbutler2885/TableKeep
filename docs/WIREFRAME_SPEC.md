# Wireframe Specification (v1 Shell)

## Desktop Wireframe
- Left Sidebar
  - Logo/title
  - Nav list: Character, Maps, NPCs, Notes, Rules
- Top Header (content pane)
  - Current user identity
  - Sign out button
- Main Panel
  - Character default view on first load
  - Character selector at top of panel
  - Character sheet body below selector

## Mobile Wireframe
- Top Header
  - Menu button (opens drawer)
  - Screen title
  - Optional account action
- Drawer
  - Nav list: Character, Maps, NPCs, Notes, Rules
- Main Panel
  - Same screen content model as desktop
  - Touch-first spacing

## Initial Flow Wireframe
1. User logs in
2. App resolves active campaign + role
3. App opens Character screen
4. Character selector defaults to player's character
5. User may switch screen via sidebar/drawer
